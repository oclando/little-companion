# 结构与数据边界

## 桌面层

Electron 主进程 `src/main.js` 管理桌宠、主面板、阅读、聊天与背词冒险窗口。渲染进程通过各自 preload 使用受限 IPC；模型 API 在主进程调用。

## 角色与剧情

`src/ai/cards.js` 读取 JSON / PNG 角色卡。`store.js` 保存角色定义、会话实例、事件与独立记忆。`prompt.js` 组装角色设定、当前剧情及所属角色的私人记忆。`provider.js` 负责兼容接口、流式输出与取消。

通用角色卡与会话内角色快照分开保存；修改卡片不会改写已有故事。各角色记忆按会话及实例隔离，公开对白作为共同上下文。

## 背词冒险

`src/ai/adventure.js` 管理路线、题量、作答阶段与学习履历。`screenplay.js` 校验模型返回的旁白和角色对白。剧情生成不能代替真实答题，过关由程序判定。查看记忆卡和答题记录与剧情回退分离。

## 本机数据

运行数据存放于 Electron userData 目录。模型密钥由 Electron safeStorage 加密后保存；不内置共享密钥。配置远程 API 后，角色设定、相关上下文和被召回的记忆会发送至用户选择的服务。

公开仓库只包含代码、通用素材、自动化测试和可分享的示例角色，不包含开发者本机存档。导入用户提供的角色卡后，原文可能被保留以支持导出；分享自己导出的卡片和存档前应另行检查。

## 当前限制

Live2D 目录用于素材管理，不代表已完成 Live2D 渲染。Spine 运行时为 3.8 系列，需提供匹配素材并遵守其许可。系统朗读取决于本机语音包。模型回复不保证角色一致性或学习事实正确，记忆由用户管理。
